# Data Vision Portfolio

Crea una página web de portafolio profesional moderna y minimalista con tonos grises, blancos y verde para resaltar, para un Analista/Científico de Datos. Incluye las siguientes secciones: Encabezado con mi nombre y biografía corta; Sección de Proyectos con tarjetas interactivas que muestren métricas principales, etiquetas de tecnologías (Python, SQL, Power BI) y botones hacia GitHub y ver demo; Sección de Habilidades por categoría; y Formulario de contacto con enlaces a LinkedIn y GitHub.
